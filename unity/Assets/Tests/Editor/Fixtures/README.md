# Audio fixture

`jfk.wav` is the public-domain John F. Kennedy speech excerpt shipped in
[whisper.unity](https://github.com/Macoron/whisper.unity/tree/529a628a915a97799e89e061af9cb7c71407124d/Assets/Samples/1%20-%20Audio%20Clip).
It verifies native model loading, transcription, and the common Runtime input route without a microphone or Python server.
